How to use the COPP Analytic Tool

Phase 1 — Upload & Validate

  1. Upload one or more dossier files (.xlsx, .xls, or .csv) by dragging them onto the drop zone or clicking it. CERS and DLam exports work as-is. Entity dossiers with banner rows, multiple sections per sheet (Contributions Given / Received, Expenditures Made), per-year tabs, and subtotal rows are detected automatically: sections are consolidated into an All Transactions sheet with Entity, Year, Flow, Quarter, Employer, Occupation, and Recipient Type columns derived, and subtotal rows excluded so totals are never double-counted. Contact, Identity, Registrations, and Source Reports sheets are kept and feed their own reports.
  2. An import check runs on every dossier: the tool reconciles its consolidated totals against the dossier's own Summary sheet, year by year and flow by flow, and verifies every sheet was readable. If problems are found you get three choices: Attempt automatic repair (re-reads unreadable sheets with a best-effort parser, infers missing headers from the data, assigns the flow using the Summary sheet, and records everything in the change log), keep the file as-is, or remove it. A clean check is confirmed in the status bar.
  3. Review the data preview. The tool detects column types (amounts, dates, names, locations) automatically.
  4. Run the error scan. Each finding can be corrected inline, auto-fixed, or accepted as-is. You can also click any cell in the preview to edit it directly.
  5. Every change is recorded in the change log, which is included in all exported reports for a complete audit trail.

Phase 2 — Analyze & Report

  1. Choose the analysis scope: the current sheet, the current file's consolidated All Transactions, or All files combined. Combined scope stacks every uploaded dossier with an Entity column and unlocks the cross-entity reports (shared counterparties, opposing activity, possible transfers).
  2. Select reports from the prewritten library, or click Analyze my data to have the tool recommend a slate of reports based on the columns it found. You can select several, or all of them.
  3. Or switch to Ask your own question and type a plain-language query. With AI enabled (Netlify deployment with an API key), answers are generated from the most relevant rows in your data.
  4. Each result includes a written analysis, key figures, a chart, and a data table. The tool also suggests follow-up reports after each run.
  5. Download any single report or the full session as XLSX, CSV, or PDF. Every export includes the Phase 1 change log.
  6. Enhanced workbook exports a v2-style workbook for the current scope: every section sheet plus a generated Analysis sheet containing consolidated line items and four pivot blocks (spend by party, recipient concentration with cumulative share, expenditures by quarter, candidate vs committee/measure). With combined scope, the Analysis sheet carries an Entity column for cross-dossier work.

Privacy

All parsing, validation, and built-in analysis run entirely in your browser. Data leaves your machine only if you enable the AI assistant, and then only the small set of rows relevant to your question is sent.

Saving your work

Use Save session in the header to download a session file containing your data, corrections, and results. Resume later with Resume saved session.
